# DMMgame Character Vault

在自己的电脑上整理和浏览游戏角色资源。可以按角色查看立绘、CG、动画、语音和已支持的剧情，搜索角色、收藏角色，并按需要下载对应分类。

这是独立制作的本地工具，与游戏运营商没有关联。各游戏的支持程度不同，当前安装版本包含哪些游戏，以首页显示为准。

## 开始使用

1. 安装 **Node.js 22 或以上版本**，确认安装目录已加入环境变量 **`PATH`**。重新打开终端，能运行 `node -v` 和 `npm -v` 即可。
2. 下载并解压本项目，在包含 **`package.json`** 的项目根目录打开终端。
3. 依次运行下面的命令，安装项目依赖并启动：

   ```sh
   npm ci
   npm start
   ```

4. 启动后会自动打开浏览器，选择游戏，再选择角色。默认地址是 `http://127.0.0.1:8787`。
5. 第一次没有头像是正常的。支持在线更新的游戏可以点击 **“拉取新角色”**；也可以打开角色，按需要下载立绘、CG、语音等分类。

Windows 用户也可以双击 **`start.cmd`**，脚本会在首次启动时自动安装运行依赖。macOS/Linux 用户使用上面的 npm 命令。Windows 是当前主要验证环境，其他系统的音频和视频格式支持可能不同。

初始角色目录只包含文字和资源映射，不附带角色头像、CG、立绘、语音或账号凭据。素材在使用时下载到自己的电脑。

**DOTABYSS、Muv-Luv、童话边境、少女艺术绮谭** 的 Unity 资源解包还需要 Python。项目已使用 Python 3.13 验证：安装 Python 后，在项目根目录运行 **`npm run setup:python`**，按提示选择游戏，即可自动创建独立环境并按该游戏的 `requirements.txt` 安装依赖。Windows 用户也可双击 **`install-python.cmd`**；使用多个 Unity 游戏时分别选择安装。千年战争、花骑士的当前下载流程不需要 Python。

资源服务器失效、地区限制、文件下架或授权过期，都可能导致部分下载失败。需要账号授权或有效签名的素材并不一定能直接下载；本工具不会绕过这些限制。

在不登录游戏账号的独立环境中，已验证花骑士、千年战争、童话边境、Muv-Luv 和 DOTABYSS 的立绘及 CG／动画样本可拉取。童话边境和 Muv-Luv 的剧情正文接口需要账号授权，匿名状态下无法获取。测试覆盖的是样本资源，不保证所有角色、分类或未来版本均可下载。大文件下载中断时可重试，已保存的完整文件会保留。

## 角色列表如何更新

每个游戏独立处理自己的目录格式。支持在线更新的模块会请求角色主数据或资源目录，把新结果合并到本地角色列表，并补充必要的图标或用于识别角色的少量资料。更新列表不会自动下载全部角色的 CG 和立绘。

DOTABYSS 会检查公开客户端对应的资源版本和目录校验值。目录里只有角色线索、没有可用资源的条目会显示 **“实装待确认”**；这是根据资源目录作出的判断，不代表官方公布的实装状态。

以后再次点击“拉取新角色”，如果新版目录已经包含该角色对应的可用资源，列表会更新，并开放对应分类的下载入口。实际能否下载仍取决于资源是否可访问；仅有角色编号并不能保证素材已经上线。

## 播放器如何工作

界面使用 **TypeScript、HTML 和 CSS**；本地服务负责下载和文件管理，Python 负责需要 Unity 解包的游戏。每个游戏保留自己的资源解析、图片合成和播放逻辑。

静态图片直接由浏览器显示；Spine 和 Live2D 由各自的网页运行库渲染；视频和语音使用浏览器媒体能力。剧情播放器读取已解析的脚本，按指令切换画面、动画、配音与界面。

DOTABYSS、Muv-Luv 和少女艺术绮谭的播放器 UI 在首次下载剧情时自动获取，也可在角色剧情页点击“下载播放器 UI”。界面图片、字体与布局只保存到本地，完整缓存会供对应游戏的所有角色使用，更新角色列表不会重复下载；缺失文件优先从已缓存的资源包修复。

## 资源从哪里来

模块根据游戏的角色主数据、资源清单及客户端使用的资源地址，向对应的游戏服务器或 CDN 请求文件。原始文件下载到本地后，再按该游戏的格式解析、解包、关联角色，必要时合成图层或转换音频。

开发时会使用有权访问的浏览器网络记录分析格式；日常使用不要求安装 HAR 解包工具。发行包不包含原始网络记录、登录请求、Cookie、访问令牌或私人签名地址。

## 本地文件与常见问题

下载数据位于 `parsed-data/游戏标识/`：

| 目录 | 用途 |
| --- | --- |
| `metadata` | 角色目录、资源映射和来源信息 |
| `cache` | 下载原件与校验清单，可清理，之后按需重建 |
| `state` | 下载任务状态、已知缺失资源等记录 |
| `library` | 播放器使用的图片、动画、音频及索引 |

关闭程序后再手动清理数据。删除 `cache` 不会删除 `library` 中的成品，但重新解包可能需要再次下载原件。空资源目录可以删除，下载时会自动创建。需要保留本地素材时，备份整个 `parsed-data` 文件夹。

**启动后没有自动打开网页：** 手动访问 `http://127.0.0.1:8787`。端口被其他程序占用时，可运行 `npm start -- --port 8788`。

**提示 Python 环境不存在：** 安装 Python 后，在项目根目录运行 `npm run setup:python`，为当前游戏安装依赖；Windows 用户也可双击 `install-python.cmd`。

**下载完成但页面没有变化：** 点击刷新，并查看任务提示；部分资源可能仍未获得或尚未适配。

**使用 Fake-IP 代理下载：** 内置游戏资源域名的 HTTPS 下载可自动兼容 Clash / Mihomo 常见的 IPv4 Fake-IP 池（`198.18.0.0/15`），沿用正常工作的 TUN 代理，无需单独添加域名排除规则。此例外仅限程序内置的精确域名和 443 端口；其他域名、HTTP、IPv6 私有地址及其他自定义地址池仍受公网地址检查限制。

**动画或视频无法播放：** 使用支持 WebGL 的现代浏览器并启用硬件加速。不同浏览器支持的音视频编码不同。
